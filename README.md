**NEON QUIZ** — Платформа интерактивных квизов
Full-stack веб-приложение для создания и проведения викторин в реальном времени. Интеграция Socket.IO обеспечивает мгновенную синхронизацию между ведущим и игроками: участники подключаются по PIN-коду комнаты, а организатор управляет ходом игры, таймером и выводом финального лидерборда.

**Функциональность**  
Система ролей:  
Организаторы (Супер-админ и простые админы) — управление контентом, комнатами и запуском сессий.  
Участник — подключение к игре по уникальному коду.

Конструктор квизов: Настройка категорий, лимитов времени, загрузка изображений и выбор типа ответов (одиночный или множественный выбор).

Real-time геймплей: Синхронное отображение вопросов у всех игроков через веб-сокеты и автоматический расчет баллов на сервере.

Аналитика: Интерактивная таблица лидеров по окончании викторины и история сессий в личном кабинете.

**Стек технологий**  
Frontend:  
React.js,  
React Router DOM,  
CSS3 (Variables & Animations)

Backend:  
Node.js,  
Express.js

Real-time связь:  
Socket.IO

База данных:  
MySQL (локальная сборка через XAMPP)

**Структура репозитория**  
root/  
├── backend/          # Серверное приложение  
├── frontend/         # Клиентское приложение  
└── neon_quiz_db.sql  # Дамп базы данных

**Установка и локальный запуск**  
**1. Настройка базы данных**
Откройте XAMPP Control Panel и запустите модули Apache и MySQL.

Перейдите в веб-интерфейс phpMyAdmin по адресу http://localhost/phpmyadmin.

Создайте новую базу данных с именем neon_quiz.

Выберите созданную БД, перейдите во вкладку Импорт (Import), выберите файл neon_quiz_db.sql из папки проекта и нажмите Вперед (Go).

**2. Запуск серверной части (Backend)**
В терминале перейдите в директорию сервера, установите зависимости и запустите NodeJS-скрипт:

cd backend  
npm install  
node index.js


Сервер запустится и начнет прослушивать WebSocket-соединения.

**3. Запуск клиентской части (Frontend)**
В новом окне терминала перейдите в папку фронтенда, установите пакеты и запустите локальный сервер разработки:

cd frontend  
npm install  
npm start
