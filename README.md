# NEON QUIZ — Веб-платформа для интерактивных квизов

Платформа для создания и проведения викторин в реальном времени. Благодаря интеграции **Socket.IO**, взаимодействие между ведущим и игроками происходит мгновенно: участники подключаются по уникальному коду комнаты, а организатор синхронно запускает вопросы с таймером и выводит финальный лидерборд.

---

Функциональность

* **Система ролей:** Организатор (создание контента, управление комнатами) и Участник (подключение к игре по коду).
* **Конструктор квизов:** Настройка категорий, лимита времени, поддержка изображений и типов вопросов (одиночный или множественный выбор).
* **Игровой процесс (Real-time):** Синхронный вывод вопросов и запуск таймера через веб-сокеты, автоматический расчет баллов на стороне сервера.
* **Статистика:** Интерактивная таблица лидеров в конце игры и история сессий в личном кабинете.

---

Стек технологий

* **Frontend:** React, React Router DOM, CSS3
* **Backend:** Node.js, Express.js
* **Real-time связь:** Socket.IO
* **База данных:** MySQL (сборка XAMPP)

## Установка и запуск

### 1. База данных

1. Запустите **Apache** и **MySQL** в XAMPP Control Panel
2. В phpMyAdmin (http://localhost/phpmyadmin) создайте базу данных с именем `neon_quiz`
3. Импортируйте файл `database/quiz(1).sql` в созданную БД

### 2. Запуск сервера (backend)

```bash
cd backend
node index.js

### 3. Запуск клиента(frontend)
cd frontend
npm install
npm start
